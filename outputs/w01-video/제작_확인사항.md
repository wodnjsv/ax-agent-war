## 편집 원칙과 실제 경로 차이

- 정상 직접 처리, 전체 자동 기본, CEO 조건 가정, 회수일 지연은 초기화로 나눈 별도 실행입니다. 화면 상단 자막으로 구분합니다.
- 실제 사용 원본은 B_base.webm, B_continue.webm, E_final_takes.webm입니다. E에는 재촬영한 회수 지연·거절·정상 컷이 들어 있습니다. 다른 시험 촬영본은 최종 영상에 사용하지 않았습니다.
- 수요는 예시 문장으로 실제 AI 정리를 호출한 뒤, 증가율과 품목별 값을 정해진 예시 값과 동일하게 직접 확인·수정해 등록했습니다. 예시 값 넣기 버튼을 누르는 계획과는 조작 경로가 다릅니다. 예시 문장은 가상 회신임을 자막에 표시했습니다.
- AI 대기 두 곳과 기본 경로의 날짜 대기 한 곳만 8배속입니다. 해당 구간 내내 배율을 표시했습니다. 판단 근거·승인 이유·현금 영향·거절 사유·데이터 흐름 카드는 모두 정속입니다.
- 다른 대기·스크롤 여백·준비 조작은 컷으로 생략했습니다. 날짜·시나리오가 바뀌는 구간은 제목으로 알립니다.
- 직접 처리 추가 컷의 날짜 진행 중 일시적인 응답 오류 화면이 있었지만 이후 7월 20일 상태와 경위가 실제 표시됨을 확인했습니다. 오류 화면은 최종본에 포함하지 않았습니다.

- 영상은 로컬 파일로 제작했습니다. 대회 사이트 제출·업로드는 수행하지 않았습니다.

프레임별 원본 구간·배율·완성 구간은 W01_최종편집.json, 자막은 W01_시연영상_자막.srt에 있습니다. 최종 파일 재생 데이터 검사는 W01_최종검수.json에 기록합니다.

## 태형 음성판 추가 제작

위 기록은 최초 무음판에 대한 기록입니다. 이후 요청에 따라 Vrew 웹 편집기에서 현재 설명 자막 56개를 **태형 / Eleven v4 / 속도 +1**로 실제 음성 생성했습니다. AI 호출·날짜 진행 대기 3개 구간은 읽지 않습니다. 영문 약어와 기안 번호는 읽기 쉬운 한글로 바꾸고 긴 문장은 같은 의미로 줄였습니다.

- `W01_태형음성.wav`: Vrew에서 전체 클립을 WAV로 내보낸 실제 음성입니다. 48kHz 스테레오, 321.656초입니다.
- `W01_태형음성_타임라인.srt`: Vrew에서 내보낸 최종 음성 시간표입니다. 56개 문구가 더빙용 자막과 일치하며 중첩·역전이 없습니다.
- 배속 표시는 사용자 수정 요청에 따라 **오른쪽 위 작은 배지 하나**로 정리했습니다. 큰 중앙 배너와 사전 예고는 사용하지 않습니다.
- AI 대기 두 곳에는 `AI 호출 대기 · 8배속`과 실제 대기 약 9초/22초를, 날짜 대기에는 `날짜 진행 · 8배속`을 표시합니다. 해당 대기 구간 내내 표시합니다.
- 음성판의 배속 구간은 약 00:36.25–00:37.33, 01:24.23–01:26.90, 02:29.00–02:29.75입니다. 정확한 프레임 경계는 최종 검수 기록을 기준으로 합니다.
- 음성 길이에 맞춰 늘어난 구간은 원본 영상을 정속 재생한 뒤 해당 구간의 마지막 화면을 유지합니다. 판단 화면을 추가로 배속하지 않습니다.
- 원래 화면에 들어간 자막을 사용하며 Vrew의 추가 자막 표시는 껐습니다. 데이터 흐름 카드·포인터·실제 작동과 모의 처리 구분은 유지합니다.
- `W01_시연영상_태형음성_작은배속.vrew`는 생성된 음성·타임라인을 보존하고 내장 원본 영상만 작은 배속 표시판으로 바꾼 편집 파일입니다. ZIP 무결성과 음성·타임라인 보존을 확인했습니다. 수정 프로젝트를 Vrew에서 다시 여는 검증은 하지 않았습니다.
- `W01_시연영상_배속강조.mp4` 및 `W01_시연영상_태형음성.vrew`는 큰 배너가 들어간 중간본입니다. 최종본 선택 시 사용하지 않습니다.

태형 음성 생성과 WAV·SRT 내보내기는 Vrew에서 수행했고, 최종 영상의 시간 조정·음성 결합은 로컬에서 수행했습니다. 최종 MP4는 H.264 영상과 48kHz 스테레오 AAC 음성을 포함합니다. 세 배속 표시, 재무·Corevia 데이터 흐름 카드, 마지막 장면을 최종 MP4에서 다시 확인했습니다. 대회 제출은 하지 않았습니다.

최종 MP4 검수에서 7,720프레임이 음성 결합 전 영상과 픽셀 단위로 일치했습니다. 56개 발화 구간 모두 음성이 있고, 배속 대기 3구간은 무음입니다. 클리핑은 없으며 파일 크기는 16,238,600바이트입니다. 모든 문장의 발음을 직접 청취한 검수는 하지 않았습니다. 상세 결과는 `W01_태형음성_최종검수.json`과 `W01_태형음성_영상검수.json`에 있습니다.

## 말속도·문장 간격 수정판

- 소개 상단의 ` · 무음 자막`만 제거했습니다. 실제 화면 녹화 표기는 유지합니다.
- Vrew에서 생성한 기존 태형 음성을 음높이 변화 없이 1.10배로 처리했습니다. 문장 내부 쉼은 유지하고, 발화 앞뒤 보호 여백을 두었습니다. 새 음성을 호출한 것은 아닙니다.
- 필수 배속 대기를 제외한 문장간 무음 중앙값은 0.710초에서 0.387초로, 90백분위는 2.582초에서 1.264초로 줄었습니다. 근거를 읽는 일부 구간에는 더 긴 여백을 남겼습니다.
- 56개 음성과 화면 자막을 같은 새 타임라인에 배치했습니다. 화면 자막 원문은 `W01_시연영상_태형음성_템포수정.srt`에 있습니다.
- 원본의 정지 구간 1,187프레임을 생략하고 필요한 끝 화면 111프레임을 추가해 6,322프레임으로 만들었습니다. 일반 화면은 정속이며, 기존 배속 대기 3곳의 프레임과 길이는 유지합니다. 컷은 문장당 최대 한 곳입니다.
- 중요 판단 근거는 최소 4초, 데이터 흐름 카드는 최소 5초를 확보했습니다. 원래 구간이 이보다 짧은 경우에는 원래 길이를 유지했습니다. 소개는 약 22.3초로 줄었습니다.
- 원본→새 영상의 보존·생략 프레임과 음성 배치는 `W01_태형음성_템포수정_타임라인.json`에 기록했습니다. 기존 영상·음성·프로젝트 파일은 덮어쓰지 않았습니다.
